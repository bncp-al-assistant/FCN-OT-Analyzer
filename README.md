# TCN OT 분석 시스템

HENC & TCN Zone 월별 타임시트(.xlsx) 두 개를 올리면 **전달과 이번 달의 평일 OT·휴일 OT를 비교**하는 웹 도구입니다.
비교 결과에는 휴일·평일 일수 변화, 작업자별 근무 시간대 변경, 시트 계산 오류 표시가 함께 나옵니다.

설치하거나 서버를 둘 필요가 없습니다. 브라우저에서 `index.html`을 열면 되고, 파일은 브라우저 안에서만 읽으며 어디에도 업로드되지 않습니다.

## 분석 항목

| 구분 | 내용 |
|---|---|
| 달력 비교 | 전체·평일·휴일 일수, 휴일 날짜(요일), 기본급 포함 B/O(평일×2h) |
| 팀 합계 | 평일 OT(1.5배·2배), 휴일 OT 시간과 금액, 1인 1일 평균, 기본급, 월급여, 증감률 |
| 주요 변화 | 달력·평일 OT·휴일 OT·시간대 변경·인원 변동·데이터 점검을 문장으로 요약 |
| OT 증감 요인 | 작업자별 OT 변화를 **근무일수 효과**와 **패턴 효과**로 나눈 차트 |
| 근무 시간대 비교 | 평일·휴일 출근–퇴근 조합별 일수를 두 달 나란히 비교하고, 바뀌면 표시 |
| 작업자별 상세 | 31일 일별 근무표(OT 색 농도, 휴일 표시, 평소와 다른 시간대 테두리), 시간대 분포, 확인할 점 |

### 계산 기준

- **평일 OT**: 시트의 "평일근무 OT 합계" = B/O − 기본급 포함분 + 평일 E/O
- **휴일 OT**: 시트의 "휴일근무 OT 합계" = 휴일 E/O
- **휴일 판정**: 휴일 OT 수식(예: `=L8+S8+Z8+AG8`)에 들어간 날짜를 휴일로 봅니다. B/O가 비어 있는 날과 다르면 경고합니다. 수식이 없을 때는 B/O 빈 날을 쓰고, 그것도 없으면 금요일을 휴일로 봅니다.
- **휴일 근무 여부**: 휴일에는 B/W 8h가 일괄 기재되므로 E/O 유무로 셉니다.
- **근무일수 효과**: 전달 1일 평균 OT × 이번 달 근무일수 − 전달 OT
- **패턴 효과**: 나머지 차이(하루 OT 시간이 늘거나 줄어든 몫)
- **시간대 변경 판정**: 아래 중 하나에 해당하면 변경으로 표시합니다.
  - 가장 많은 출퇴근 조합이 바뀐 경우
  - 한 조합의 비중이 15%p 이상 바뀐 경우
  - 평일 1일 평균 OT가 0.25h 이상 바뀐 경우(따로 표시)
- **데이터 점검**: 다음 경우를 표시합니다.
  - 일별 합산과 시트 요약값이 다를 때
  - B/O는 있는데 B/W가 빈 날
  - 출퇴근 시간과 기록 시간이 맞지 않는 날
  - 기본급 포함 B/O 수식이 수동으로 조정된 경우(`-28` 등)
  - 시급이 바뀐 경우

## 사용법

### 1) 바로 쓰기
`index.html`을 더블클릭해서 브라우저로 엽니다(인터넷 연결 필요: 엑셀 읽기 라이브러리와 글꼴을 CDN에서 받습니다).
그다음 전달·이번 달 타임시트 두 개를 끌어다 놓습니다. 순서는 상관없고, 파일명·시트명에서 월(July, August, 07월 등)을 읽어 알아서 정렬합니다.

### 2) GitHub Pages로 팀과 공유
1. 이 저장소를 GitHub에 올립니다(아래 참고).
2. 저장소의 **Settings → Pages → Source**를 **GitHub Actions**로 바꿉니다.
3. `main`에 push하면 테스트가 통과한 뒤 자동 배포됩니다. 주소는 `https://<계정>.github.io/tcn-ot-analyzer/` 형식입니다.

> 비공개 저장소에서 Pages를 쓰려면 GitHub 유료 플랜이 필요합니다. 페이지에는 익명 예시 데이터만 들어 있고, 실제 타임시트는 각자 브라우저에서 올려서 봅니다.

### 3) 터미널에서 요약 보기
```bash
npm install
npm run analyze -- 전달.xlsx 이번달.xlsx
```

## 개발

```bash
npm install
npm test        # samples/ 의 익명 예시로 파싱·비교 검증
npm start       # http://localhost:8080 로컬 서버
npm run embed   # samples/*.xlsx 를 바꾼 뒤 js/sample-data.js 재생성
```


### 지원하는 시트 양식
첫 번째 시트에서 다음을 찾습니다. 열 위치가 바뀌어도 머리글 이름으로 찾습니다.
- `TIME` 머리글과 날짜 행(1~31)
- 작업자별 `IN / OUT / B/W / B/O / E/O` 5줄 묶음
- 요약 열 `기본근무(B/W, B/O)`, `평일근무 OT(합계, 1.5, 2)`, `휴일근무 OT(횟수, 합계)`, `월급여`, `기본급`, `평일OT($)`, `휴일OT($)`, `보너스`
- 상단 `근무일`, `휴일` 값

작업자는 E/N(사번)으로 두 달을 맞추고, 사번이 없으면 이름으로 맞춥니다.
